# Zapstick presentation film

Three localized, two-minute films are served from `public/videos/`:

- `zapstick-intro-fr.mp4` and `.jpg`
- `zapstick-intro-en.mp4` and `.jpg`
- `zapstick-intro-pt-br.mp4` and `.jpg`

The storyboard defines twelve contiguous scenes. Each frame is drawn from its
timestamp, with public local meme frames, the official Zapstick mark, vector
interface illustrations, animated gestures and localized copy. No private
collection, account, remote screenshot or synthetic voice is used.

## Rebuild

Use the project's installed Node dependencies and a local FFmpeg executable.

```sh
python3 scripts/intro/music.py
node scripts/intro/render.mjs --audio /tmp/zapstick-intro-music.wav
```

The music script's output path is documented in that script. Pass its WAV path
with `--audio` if it differs. A single language can be rendered with
`--locale fr`, `--locale en`, or `--locale pt-BR`.

```sh
node scripts/intro/render.mjs --stills
```

This creates representative scene images under the ignored `outputs/intro/`
directory and refreshes the public poster JPEGs without encoding any video.

The MP4s contain 2,880 frames at 24 fps, 1280 × 720, H.264 with limited-range
BT.709 `yuv420p`, AAC stereo music and a front-loaded MP4 index (`faststart`).
The target video bitrate is 380 kbit/s, with a 450 kbit/s ceiling and 64 kbit/s
audio, keeping each two-minute film below 8 MB.

An optional `--normalize-only` operation converts an existing first-pass
full-range film to limited-range BT.709. Normal rendering already does this
conversion and does not require that operation.

The WebVTT companions contain the twelve localized title/body cues. Attribution
for reused meme media remains in `public/memes/SOURCES.txt`; the backing music
is the original composition generated by `music.py`.
